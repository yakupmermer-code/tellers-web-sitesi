# Tellers Web Sitesi

Tellers Creative Communications ajansının kurumsal web sitesi.
Arpeggio (Framer) teması referans alınarak Next.js ile sıfırdan geliştirilmiştir.

## Sayfalar

Ana Sayfa · Hakkımızda · Portfolyo (+17 marka detay) · Hizmetlerimiz · Blog (8 yazı) · Kariyer · İletişim

## Geliştirme

```bash
npm install
npm run dev        # http://localhost:3000
npm run build      # production build
```

## Yapı

- `app/` — Next.js App Router sayfaları
- `components/` — paylaşılan bileşenler (Header, Footer, ReferansBandı, slider'lar)
- `content/` — tüm site içeriği (markalar, bloglar, hizmetler) TypeScript verisi olarak
- `public/assets/` — Drive'dan indirilen görsel/videolar

## Marka

- Renk: `#0a0a47` · Fontlar: Avenir Next + Bodoni Moda (serif vurgu — DENEME, Didot yerine) · Slogan: "Duyulan unutulur, anlaşılan kalır."
